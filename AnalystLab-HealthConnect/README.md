# HealthConnect Clinic — AnalystLab Africa Experience Lab

## About This Repository

This repository documents my work as a **Data Analytics Track** intern on the **AnalystLab Africa Experience Lab** internship programme, working on the **HealthConnect Clinic** project.

**Project Title:** Improving Patient Appointment Attendance and Healthcare Support Using Data and AI

**Business Question:** How can HealthConnect Clinic use data and AI to reduce missed appointments and improve the patient support experience?

> HealthConnect Clinic is a fictional healthcare provider used for this internship programme. All data is anonymized and simulated for learning purposes.

## Project Overview

HealthConnect Clinic manages appointment-based services and is looking to reduce missed appointments (no-shows), better understand attendance patterns, and improve administrative support for patients. This repository tracks my progress through each week of the internship, applying data analytics techniques to explore the problem and produce actionable insights.
